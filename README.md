Solmar: Sunset Run — a top-down open-city driving + on-foot action game set in the fictional
sun-soaked coastal city of Solmar. Steal cars, run missions for Tía Carmen, dodge the Port Cats,
and outrun the heat across the whole map.

Marisol "Sol" Reyes drives a battered taxi by day and runs special deliveries by night. She
needs $5,000 to buy back her late father's taxi medallion from the Port Cats before the city
impounds it — six chained missions, from a first fare at the marina to a full-heat getaway
across the whole city to the observatory.

## Run it

```sh
node game/serve.ts
# open http://localhost:8080
```

WASD / arrows — drive or walk · E — enter / steal a car · Space — handbrake / punch ·
Shift — run · P — pause · M — mute.
